# 网关管理面板

`gateway` 子命令可以托管 core 的 ToolRegistry 管理面板，并加载网关管理扩展，从而提供
三个运维页面：

| 页面 | 管理内容 |
|------|----------|
| **Keys（密钥）** | OpenAPI 与 MCP 前端接受的入站客户端密钥 |
| **Frontends（前端）** | 每个网关前端的启用标记与挂载路径 |
| **Sources（来源）** | 在运行期添加、重试或移除的工具来源 |

该面板是运维面。它使用 core 面板自己的令牌与会话鉴权，刻意不属于保护工具前端的
`--tokens` 集合。客户端密钥无法访问这些页面中的任何内容。

## 启用面板

管理前端默认禁用。用 `--admin` 启用，并用 `--admin-token` 或更推荐的
`--admin-token-file` 提供运维令牌，避免密钥出现在进程列表中：

```bash
toolregistry-server gateway \
  --config tools.yaml \
  --keys-db keys.db \
  --admin \
  --admin-token-file operator-token.txt
```

- 启用前端但未配置运维令牌会导致启动失败。
- 网关的对外令牌无法打开面板：只携带 `--tokens` 凭据的请求会得到 `401`。
- 挂载路径默认为 `/admin`；用 `--admin-path` 或
  `gateway.frontends.admin.path` 修改。
- 托管面板要求 core `toolregistry` 提供管理扩展契约（`ADMIN_EXTENSION_API == 1`，
  即 core 0.21.0 或更新版本）。旧版 core 上该前端会以明确错误拒绝启动；默认配置
  不会加载它。

启用后，面板外壳位于挂载路径（默认 `http://host:8000/admin/`），网关页面位于其下：
`/admin/ext/gateway/keys`、`/admin/ext/gateway/frontends` 与
`/admin/ext/gateway/sources`。在控制台导航中该扩展是一个名为 **Gateway** 的标签页，
默认打开 **Keys**。

禁用管理前端后，面板根路径及其下所有扩展页面在下一个请求返回 `404`，无需重启。

## Keys 页面

Keys 页面管理 OpenAPI 与 MCP 前端接受的限定作用域入站密钥。它使用 `--keys-db`
指定的存储；未配置该选项时页面返回 `503`，工具前端只保留静态 `--tokens` 凭据。
面板与工具前端共享同一个数据库，因此在这里创建的密钥在下一个请求即被前端接受，
撤销的密钥在下一个请求即被拒绝。

表格每行一个密钥：

| 列 | 含义 |
|----|------|
| 名称（Label） | 面向运维的名称 |
| 权限范围（Scopes） | 命名空间，以及按工具的允许/拒绝覆盖 |
| 创建时间（Created） | 创建时间 |
| 过期时间（Expires） | 过期时间，或 `永不` |
| 最近使用（Last used） | 最近一次成功认证的时间 |
| 状态（Status） | `有效`、`已过期` 或 `已撤销` |

已撤销与已过期的密钥仍保留在表格中，便于查看历史。存储只保留密钥的哈希；任何响应
与静态资源都不包含明文密钥。

### 创建密钥

填写表格下方的表单：

- **名称（Label）** — 必填；仅用于显示，不要求唯一。
- **权限范围（Scopes）** — 以逗号分隔的命名空间列表。`*` 匹配所有命名空间，
  `web/*` 匹配 `web` 及其下的任意命名空间。
- **按工具覆盖（Tool overrides）** — 每行一个 `tool=allow` 或 `tool=deny`，例如
  `web-dangerous=deny`。覆盖始终优先于命名空间列表，因此在允许的命名空间中拒绝
  某个工具、或在命名空间之外允许某个工具，都通过它表达。
- **过期时间（Expires）** — 可选的本地时间。网关会把它转换为绝对时间戳发送，存储会
  拒绝过去的时间。

空的命名空间列表且没有覆盖，会创建一个什么都调用不了的密钥；这是失败即关闭的默认。

创建成功后，页面只显示一次密钥，并提供复制按钮：

!!! warning "密钥只显示一次"
    完整密钥只出现在创建响应中，该响应带有 `Cache-Control: no-store`。页面不会
    保存它，事后也无法找回。若关闭对话框时没有复制，只能重新创建一个密钥。

### 撤销密钥

**撤销（Revoke）** 会先请求确认，然后立即把密钥标记为已撤销。使用该密钥的客户端在
下一次请求时被拒绝。撤销是幂等的，并保留最初的撤销时间。

### 限定作用域的密钥与延迟工具

!!! note "当前限制"
    限定作用域的密钥看不到也无法调用发现代理 `discover_tools` 与
    `call_deferred`：它们会从限定作用域的 `tools/list` 中隐藏，并在调用时被拒绝，
    MCP 与 OpenAPI 两个面皆如此。这两个代理可以绕过逐次调用的作用域检查，因此在
    作用域感知的发现功能落地之前保持失败即关闭
    （[#195](https://github.com/Oaklight/toolregistry-server/issues/195)）。
    运维身份与静态令牌不受影响。

## Frontends 页面

Frontends 页面列出每个网关前端 —— `openapi`、`mcp`、`sse` 与 `admin` ——
以及其路径、传输与启用标记，并修改与 `gateway.list_frontends()`、
`gateway.update_frontend()` 相同的注册表。

- **启用/禁用** 在下一个请求生效。被禁用的前端在其应用或注册表运行之前返回 `404`，
  其他前端继续服务。切换不会重建 MCP 会话管理器。
- **路径** 必须以 `/` 开头，必须唯一，且不能包含空白、`?`、`#` 或 `//`。新路径在
  下一个请求生效。
- **持久化**：变更在复制 `<config>.bak` 之后写回配置文件。结果行会说明是否已持久化；
  未持久化时页面显示原因，而不是假装成功。仅运行期部署（没有配置文件路径，或使用
  `--no-config-write`）只在内存中保留变更，直到进程退出。
- **注释丢失**：重写 JSONC 配置会丢失其中的注释。更新响应会带上警告，页面会显示它；
  若注释重要，请改用 YAML 配置或保留副本。
- **后端限制**：多个前端必须使用 `fastapi` 后端。`--backend httpserver` 只能在
  监听器根路径提供 openapi 前端，因此启用了管理前端的网关不能使用该后端，openapi
  路径覆盖也会被拒绝而不是被忽略。

允许在该页面禁用 `admin` 前端；此后面板返回 `404`，页面本身在通过配置文件或进程
参数重新启用之前不可达。

## Sources 页面

Sources 页面显示运行期来源管理器的视图：每行一个已声明的来源，包含类型、详情、
命名空间、已启用/工具总数、状态与最近错误。

| 状态 | 含义 |
|------|------|
| `已应用`（Applied） | 来源已注册其工具 |
| `已排除`（Excluded） | 部署配置把该来源过滤掉了；进入适用范围后会注册 |
| `失败`（Failed） | 最近一次应用失败；错误已脱敏并显示在该行 |

操作：

- **添加来源（Add source）** — 选择类型（`OpenAPI`、`MCP`、`Python`），填写规范或
  服务地址，Python 来源填写模块/类，并可选填命名空间。网关校验声明，并转换为与
  配置文件相同的类型化来源对象，应用部署配置，并通过来源管理器持久化这次添加。
- **重试（Retry）** — 只对 `失败` 的来源显示。它会重新应用未改变的声明；部分注册会
  回滚，因此重试不会重复注册工具。非失败的来源保持不变。
- **移除（Remove）** — 注销该来源的工具并持久化移除。
- **替换（Replace）** — 页面没有替换控件。整体替换声明可通过扩展路由
  `PUT /admin/ext/gateway/sources/{id}` 完成，请求体与**添加来源**相同；它在一次
  差异中注销旧工具并注册新工具集合。

配置文件无法写入时，变更仍在内存中生效，页面显示未保存及其原因。只读配置不会被
报告为成功。

面板自身的 **Sources** 标签页（core 面板的部分，不属于 Gateway 页面）仍提供
预览 → 勾选工具 → 注册的流程。预览不会注册任何内容，只列出来源提供的工具；注册只
发送勾选的名称，并通过同一钩子持久化。若想在添加来源前查看工具列表，使用它；
Gateway 的 Sources 页面适合已明确知道内容的来源。

## 安全说明

- 面板及其扩展页面仅供运维使用。客户端密钥不会授予访问权限，扩展也不添加自己的
  任何鉴权代码：它继承面板的会话与面板的跨站防护。
- 扩展资源是通过面板资源处理器提供的静态 JavaScript 与 CSS。任何资源都不包含密钥，
  页面只在内存中保留一次性密钥。
- 面板会在页面处理器运行之前检查每个请求路径；扩展下的未知路径返回面板的 JSON
  错误结构。
